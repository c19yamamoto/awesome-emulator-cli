# Code of Conduct

We want this project to be a welcoming, respectful place to build reliable tools for local AWS testing. We welcome people of all backgrounds and experience levels.

## Expected behavior

- Be respectful, patient, and constructive.
- Focus feedback on the work and ideas, and make room for different perspectives.
- Help keep discussions useful and welcoming to everyone.

## Unacceptable behavior

Harassment, discrimination, personal attacks, intimidation, sexualized conduct, and sharing someone's private information without consent are not acceptable.

## Scope and enforcement

This applies in project spaces and when representing the project publicly. Maintainers may remove content, request changes, or restrict participation in response to unacceptable behavior.

To report a concern, contact the maintainer privately using the contact details on their [GitHub profile](https://github.com/c19yamamoto). Please include relevant links and context; do not post reports in public issues.
