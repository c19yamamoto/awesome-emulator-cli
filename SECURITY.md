# Security Policy

## Supported versions

Security fixes are provided for the latest published version. Please update before reporting an issue.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub's security advisory form](https://github.com/c19yamamoto/awesome-emulator-cli/security/advisories/new). Do not disclose an unpatched vulnerability in a public issue.

Include the affected version, impact, and steps to reproduce. The maintainer aims to acknowledge reports within five business days and will coordinate disclosure after a fix is available.

For vulnerabilities in the downloaded AWS Emulator itself, contact its maintainers through the [AWS Emulator project](https://github.com/aws/aws-emulator).
